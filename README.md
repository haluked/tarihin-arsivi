## 🎬 Nasıl İzlenir ve Oynatılır?

1. **🔴 YouTube Bölümleri:** Tablodaki `▶ YouTube` butonuna veya linkine tıklayarak doğrudan YouTube üzerinden yüksek kalitede izleyebilirsiniz.
2. **🟢 Web Arşivi (.webm) Bölümleri:** YouTube'dan kaldırılan ancak Web Arşivi üzerinden kurtarılan 144 bölüm, doğrudan video akış bağlantısı (`.webm`) içerir:
   - **Tarayıcıda:** Linke tıkladığınızda Chrome, Firefox, Safari veya Edge doğrudan videoyu oynatır.
   - **VLC / MPV Player:** Linke sağ tıklayıp *Bağlantıyı Kopyala* deyin, VLC Player'da `Medya -> Ağ Akışı Aç` menüsüne yapıştırarak kesintisiz izleyin.
   - **İndirme:** Linke sağ tıklayıp *Farklı Kaydet* diyerek veya `aria2c` / `curl` ile bilgisayarınıza indirebilirsiniz.
